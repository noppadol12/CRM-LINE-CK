## ฐานข้อมูล

- Schema: `prisma/schema.prisma` (Prisma 7 + `@prisma/adapter-pg`)
- ทุกครั้งที่ Vercel build จะรัน `prisma db push` เพื่อสร้าง/อัปเดตตารางให้ตรงกับ schema อัตโนมัติ
  ถ้าการเปลี่ยนแปลงจะทำให้ข้อมูลหาย build จะหยุดเองเพื่อป้องกัน
- ตั้ง `SEED_DEMO=true` เพื่อใส่ข้อมูลตัวอย่าง (รันซ้ำได้ ไม่สร้างซ้ำ)
- เช็คการเชื่อมต่อ: เปิด `/api/health`

## ระบบล็อกอิน

- Session เข้ารหัสในคุกกี้ (iron-session) อายุ 7 วัน, รหัสผ่านเก็บแบบ bcrypt
- `src/proxy.ts` กันหน้าที่ต้องล็อกอิน (ด่านแรก) และ `getCurrentUser()` ใน `src/lib/auth.ts` ตรวจสิทธิ์จริงทุกครั้งที่อ่านข้อมูล
- บัญชีแรก: ตั้ง `ADMIN_EMAIL` + `ADMIN_PASSWORD` แล้ว deploy ระบบจะสร้างบัญชีเจ้าของให้
- ลืมรหัสผ่าน: ตั้ง `ADMIN_RESET_PASSWORD=true` พร้อม `ADMIN_PASSWORD` ใหม่ → redeploy → ลบตัวแปรออก

## LINE Webhook

- Endpoint: `POST /api/line/webhook` ตรวจลายเซ็นด้วย `LINE_CHANNEL_SECRET`
- event ทุกตัวบันทึกลง `webhook_events` ก่อน (กันประมวลผลซ้ำเมื่อ LINE ส่งซ้ำ) แล้วตอบ 200 ทันที ประมวลผลต่อด้วย `after()`
- รองรับ: follow, unfollow, join, leave, message (ข้อความ รูป วิดีโอ เสียง ไฟล์ สติกเกอร์ ตำแหน่ง)
- **แชทกลุ่ม / แชทหลายคน**: เมื่อเชิญ OA เข้ากลุ่ม ทุกข้อความในกลุ่มเข้า CRM เป็นห้องแชทหนึ่งห้อง (`customers.chatType = group|room`)
  แสดงชื่อ/รูปคนส่ง ตอบกลับเข้ากลุ่มได้ (ทุกคนในกลุ่มเห็น) — ต้องเปิด "อนุญาตให้เข้าร่วมแชทกลุ่ม" ใน LINE Official Account Manager
  แชทกลุ่มไม่นับเป็นลูกค้าใหม่ในแดชบอร์ด/รายงาน และไม่นับในเวลาตอบแชท
- ดึงชื่อและรูปโปรไฟล์จาก LINE อัตโนมัติ (อัปเดตวันละครั้ง)
- ตั้งค่า: หน้า **ตั้งค่า → การเชื่อมต่อ LINE OA** กด "ตั้ง Webhook URL ให้อัตโนมัติ"

## หน้าแชท

- อัปเดตอัตโนมัติทุก 5 วินาที (หยุดเมื่อสลับแท็บ) เพราะ Vercel serverless ไม่มี WebSocket ถาวร
- ตอบด้วย **Reply API (ฟรี ไม่นับโควตา)** อัตโนมัติถ้าตอบภายใน ~50 วินาทีหลังลูกค้าส่งข้อความ (reply token อายุสั้น ใช้ได้ครั้งเดียว)
  ไม่ทันจะใช้ Push API (นับโควตา) พร้อม retry key กันส่งซ้ำ — ช่องพิมพ์แสดงนับถอยหลังเมื่อยังตอบฟรีได้
- โควตาข้อความเดือนนี้ดูได้ที่ ตั้งค่า → การเชื่อมต่อ LINE OA
- ส่งรูป (ย่ออัตโนมัติ ≤1 MB) และไฟล์ PDF/Word/Excel ฯลฯ ไม่เกิน 4 MB: เก็บใน Google Drive แล้วส่งลิงก์ที่มีลายเซ็น
  `/api/media/:id/:sig` ให้ LINE (รูปแสดงในแชท, ไฟล์ส่งเป็นการ์ดพร้อมปุ่ม "เปิดไฟล์") — ต้องเชื่อมต่อ Google Drive ก่อน
- รูป/วิดีโอ/เสียง/ไฟล์ดึงผ่าน `/api/line/content/:id` (ต้องล็อกอิน) — LINE เก็บไฟล์ไว้ชั่วคราวเท่านั้น
- ข้อความที่ทีมตอบจากแอป LINE OA Manager โดยตรง จะไม่ถูกส่งมาที่ webhook จึงไม่ปรากฏในประวัติ

## ดีล / ใบเสนอราคา

- ขั้นเริ่มต้น: สอบถาม → เสนอราคาแล้ว → รอโอนเงิน → เตรียม/จัดส่ง → ปิดการขาย / ไม่ซื้อ (ต้องระบุเหตุผล)
- **กำหนดขั้นเองได้** ที่ ตั้งค่า → ขั้นตอนดีล (หรือปุ่ม "จัดการขั้นตอน" บนบอร์ด): เพิ่ม เปลี่ยนชื่อ สี เลื่อนลำดับ ลบ (ย้ายดีลไปขั้นอื่นก่อน)
  "ปิดการขาย" และ "ไม่ซื้อ" เป็นขั้นของระบบ (id `WON` / `LOST`) อยู่ท้ายสุดเสมอ ลบไม่ได้ แต่เปลี่ยนชื่อ/สีได้ — รายงานใช้คำนวณยอดขาย
- ลากการ์ดเพื่อเปลี่ยนขั้น ทุกการเปลี่ยนบันทึกใน `deal_events` สำหรับรายงานอัตราปิดการขาย
- วันนัดติดตาม → แสดงใน "ต้องติดตามวันนี้" ที่แดชบอร์ด
- สร้างดีลได้จากหน้าดีล หน้าลูกค้า และข้างห้องแชท

## เก็บไฟล์ลง Google Drive

- LINE เก็บรูป/วิดีโอ/ไฟล์ไว้ชั่วคราว ระบบจึงคัดลอกไปเก็บใน Google Drive ทันทีที่ webhook เข้ามา
- โฟลเดอร์: `CK CRM - ไฟล์จาก LINE / YYYY-MM /` ชื่อไฟล์ `วันเวลา_ชื่อลูกค้า_เลขข้อความ`
- ขอสิทธิ์แค่ `drive.file` (เห็นเฉพาะไฟล์ที่ระบบสร้างเอง) refresh token เข้ารหัส AES-256-GCM ก่อนเก็บใน `app_settings`
- ไฟล์ไม่แชร์สาธารณะ — เปิดดูผ่าน `/api/line/content/:id` ที่ต้องล็อกอิน (ไฟล์ชนิดอันตราย เช่น .html บังคับดาวน์โหลด)
- ตั้งค่า: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` → หน้า **ตั้งค่า → ที่เก็บไฟล์** กด "เชื่อมต่อ Google Drive"
- Redirect URI ใน Google Cloud: `https://<โดเมน production>/api/google/callback`
- ไฟล์ที่บันทึกไม่ทัน จะลองใหม่อัตโนมัติ (ทุก ~15 นาทีเมื่อมี webhook + Cron รายวัน) หรือกดปุ่ม "บันทึกไฟล์ที่ค้างตอนนี้"

## ทีมงานและสิทธิ์

| สิทธิ์ | ทำได้ |
|---|---|
| เจ้าของ | ทุกอย่าง จัดการทีมทุกระดับ ล้างข้อมูลตัวอย่าง |
| แอดมิน | ลบลูกค้า แท็ก ข้อความสำเร็จรูป การเชื่อมต่อ LINE/Drive เพิ่ม/ปิดบัญชีเซลส์ |
| เซลส์ | ดูแลลูกค้า ตอบแชท สร้าง/แก้ดีล |

- เพิ่มทีมงาน → ระบบสร้างรหัสชั่วคราว (แสดงครั้งเดียว) ผู้ใช้ต้องเปลี่ยนรหัสเอง
- เปลี่ยน/รีเซ็ตรหัส หรือปิดบัญชี → session เก่าทุกเครื่องใช้ไม่ได้ทันที (`sessionVersion`)
- ต้องมีเจ้าของที่ใช้งานได้อย่างน้อย 1 คนเสมอ

## ความปลอดภัย

- ใส่รหัสผิด 5 ครั้ง/อีเมล หรือ 20 ครั้ง/IP ใน 15 นาที → ล็อกชั่วคราว
- header กัน clickjacking / MIME sniffing ทุกหน้า
- event จาก LINE ที่ประมวลผลไม่สำเร็จ ลองใหม่อัตโนมัติ (สูงสุด 5 ครั้ง) หรือกดปุ่มในหน้าตั้งค่า
- Cron รายวัน `/api/cron/maintenance` (ต้องตั้ง `CRON_SECRET`): ลองงานค้าง + ลบ log เก่า (login 7 วัน, webhook 90 วัน)

## แอปมือถือและแจ้งเตือน

- ติดตั้งเป็นแอปได้ (PWA): Android Chrome → "ติดตั้งแอป", iPhone Safari → แชร์ → "เพิ่มไปยังหน้าจอโฮม"
- แจ้งเตือน Web Push เมื่อลูกค้าทักแชท: เปิดที่ ตั้งค่า → แจ้งเตือนและแอปมือถือ (ตั้งแยกแต่ละเครื่อง)
  iPhone ต้องติดตั้งลงหน้าจอโฮมก่อน (iOS 16.4+) — กุญแจ VAPID สร้างอัตโนมัติ ไม่ต้องตั้งค่าเพิ่ม

## สำรองข้อมูล

- ตั้งค่า → สำรองข้อมูล ดาวน์โหลด CSV (ลูกค้า / ประวัติแชท / ดีล) เปิดด้วย Excel ได้ภาษาไทยถูกต้อง

## ขนส่ง

- เมนู **ขนส่ง**: ภาพรวม 77 จังหวัด (แบ่ง 6 ภาค) · บริษัทขนส่ง · ประวัติการส่ง
- บริษัทขนส่ง: ข้อมูลติดต่อ จุดส่งของฝั่งร้าน เวลาปิดรับ การเก็บเงิน ลิงก์ติดตามพัสดุ (`{เลขพัสดุ}`)
- จังหวัดที่ไป (`carrier_coverage`): เลือกหลายจังหวัด/ทั้งภาคได้ พร้อมสาขาปลายทาง เบอร์ ระยะเวลา
- ลูกค้า: จังหวัด ขนส่งหลัก ขนส่งสำรอง หมายเหตุจัดส่ง — แก้ได้ที่หน้าลูกค้าและข้างห้องแชท
- บันทึกการส่งของ (`shipments`): ขนส่ง เลขพัสดุ ค่าส่ง จำนวนกล่อง ผูกกับดีลได้ และส่งเลขพัสดุให้ลูกค้าทาง LINE ในคลิกเดียว
  (ข้อความสร้างให้อัตโนมัติ รวมสาขาปลายทางของจังหวัดลูกค้าและลิงก์ติดตาม) — บันทึกได้จากหน้าลูกค้า ข้างห้องแชท และเมนูการ์ดดีล
- จังหวัดที่มีลูกค้าแต่ยังไม่มีขนส่งจะขึ้นเตือนสีเหลือง
